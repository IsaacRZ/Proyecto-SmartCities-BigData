# Data Directory

This directory contains data files for the Smart Cities traffic analysis project.

## Structure

```
data/
├── raw/          # Raw data (excluded from git - large files)
│   ├── barcelona/    # Barcelona Open Data historical traffic data
│   └── sumo/         # SUMO simulation XML outputs
└── processed/    # Processed data (excluded from git - derived from raw)
    └── parquet/      # Parquet files for Spark analysis
```

## What goes here

### raw/

- **Barcelona Open Data**: CSV files downloaded from https://opendata-ajuntament.barcelona.cat/data/es/dataset/trams
- **SUMO outputs**: XML files generated by SUMO simulations (`tripinfos.xml`, `edgeData.xml`, `stats.xml`, `stopinfos.xml`)

### processed/

- **Parquet files**: Converted data optimized for Spark analysis
- **Aggregated datasets**: Summarized data from batch processing

## Note

All files in this directory are excluded from git (see `.gitignore`) due to size constraints.
Team members should share data files via external storage (Google Drive, shared network drive, etc.)

## Loading external data

Place downloaded files in the appropriate subdirectory before running analysis notebooks.
