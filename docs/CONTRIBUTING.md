# Guía de Contribución

## Antes de commitear

1. Formatear código: `black scripts/`
2. Verificar estilo: `flake8 scripts/`
3. Ejecutar tests: `pytest tests/`

## Branches

- `main`: Código en producción
- `develop`: Desarrollo activo
- `feature/nombre`: Nuevas características
- `fix/nombre`: Correcciones

## Code Review

Todo código debe ser revisado antes de merge a `main`.
